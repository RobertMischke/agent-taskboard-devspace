# Änderungen vor der Veröffentlichung prüfen

Diese Checkliste gehört zu einer Datei im Beispielordner. Das Studio zeigt ihre
Position in der Ordnerstruktur; der Bericht prüft den gesamten unterstützten Text.

- Die Aussage im Zusammenhang lesen.
- Zusätzliche Behauptungen mit vorhandenen Belegen vergleichen.
- Den Quelldiff und die Ziele vorhandener Links prüfen.
- Die geänderte Datei erneut öffnen und Feedback nachprüfen.

## Offene Punkte sichtbar halten

Ein gespeicherter Vorschlag ist noch kein geprüftes Ergebnis. Wenn eine fachliche
Frage offen ist, bleibt sie als Rückmeldung bei der Quelle. Ein Agent kann einen
Entwurf vorbereiten; die Entscheidung über die Aussage braucht den passenden Beleg.
