# Review a proposal

Review the source and the rendered text together. A cleaner sentence can
still change the meaning, so check any facts that the proposal adds or removes.

## Source changes

An edit belongs to a particular file revision. If that file changes while a
proposal is open, refresh the comparison before applying the proposal.

## Feedback

Save the reason for a change. A later reviewer should be able to understand
the decision without reconstructing the original conversation.
