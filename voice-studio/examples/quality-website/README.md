# Quality Studio example website

Eleven editable HTML pages with long-form German content, an English page,
native links, an imprint for the local example, privacy notes, FAQ, a local-only
contact form and a persistent checklist. No invented business identity or public
service promise is included. Source files are the website; there is no preview copy.

`npm start` in Voice Studio serves these files at http://127.0.0.1:5189/index.html.
The site's own assets and scripts execute there. Its review library connects to
the local Studio on port 5188. You can browse this URL independently of the Studio.

Feedback and source proposals use project `.voice-lint` metadata. Some deliberately
broad wording remains to exercise review. Do not automatically regenerate these
files after reviewing: source edits are the intended output of the workflow.
