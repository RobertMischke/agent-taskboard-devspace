Fragen zur Arbeit mit diesem Projekt

Hier findest du die wichtigsten Antworten zum Browsen, Prüfen und Bearbeiten der Beispielwebsite.

Ist das eine Kopie der Website im Studio?

Nein. Der Browser lädt diese Dateien vom lokalen Server auf Port 5189. Styles, Skripte und Navigation laufen auf diesem Server-Origin. Die eingebundene Review-Library übermittelt ausgewählte Textstellen an das Studio.

Kann ich auch Text ohne Unterstreichung kommentieren?

Ja, sofern die Textstelle eindeutig einer eingelesenen Quelle zugeordnet werden kann. Automatische Befunde sind ein Einstieg. Deine eigene Beobachtung kann auch an einer bisher unauffälligen Passage beginnen.

Wo bleibt mein Feedback?

Das Studio speichert Rückmeldungen als Metadaten im registrierten Projekt. Sie bleiben nach einem Neustart erhalten. Der Text der Website wird erst geändert, wenn du einen vorbereiteten Quelldiff ausdrücklich übernimmst.

Warum lässt sich nicht jede sichtbare Stelle ändern?

Die sichtbare Seite und ihre Quelle müssen übereinstimmen. Dynamisch zusammengesetzte Texte, veraltete Quellstände oder mehrdeutige Stellen können eine sichere Zuordnung verhindern. Das Studio soll in solchen Fällen keinen anderen Text stillschweigend bearbeiten.

Was passiert mit Markdown?

Bei Markdown öffnest du einen Projektordner und navigierst durch dessen Unterordner und Dateien. Der Bericht bezieht sich auf die ganze Datei. Links und Formatierung bleiben beim Anwenden unterstützter Textänderungen erhalten.

Prüft ein Sprachmodell die Inhalte?

Die lokalen Regeln benötigen kein Sprachmodell. Eine semantische Prüfung wird als eigener Auftrag über den Coding-Agent-Runner ausgeführt, wenn die lokale Route konfiguriert ist. Ihre Ergebnisse bleiben überprüfbare Vorschläge; sie dürfen keine Quelle selbständig ändern.

Kann ich diese Website außerhalb des Studios öffnen?

Ja. Benutze die Schaltfläche für einen eigenen Tab oder öffne die lokale Website-Adresse direkt. Das normale Verhalten der Website hängt nicht davon ab, ob das Review-Panel geöffnet ist.
