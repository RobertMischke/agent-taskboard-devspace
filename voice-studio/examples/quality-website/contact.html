Eine Frage zum Review vorbereiten

Eine gute Frage nennt die betroffene Seite, die offene Entscheidung und den erwarteten nächsten Schritt. So kann die andere Person im richtigen Zusammenhang antworten.

Was in einer Anfrage stehen sollte

Gib den Link zur Seite und die Textstelle an. Beschreibe anschließend, was unklar ist: eine Funktion, ein Versprechen oder eine Formulierung. Falls bereits ein Vorschlag vorliegt, nenne auch die noch fehlende Information. Ein Screenshot kann ergänzen, ersetzt aber nicht den Bezug zur Quelle.

Einen lokalen Entwurf ausprobieren

Dieses Formular demonstriert das normale Skriptverhalten einer Website im Studio. Es erstellt nur eine Rückmeldung auf der Seite und versendet keine Nachricht. Verwende keine echten personenbezogenen Daten für dieses Beispiel.

Feedback direkt am Text

Für die eigentliche Arbeit im Voice Studio ist das Markieren einer Passage meist der kürzere Weg. Die Rückmeldung erhält dadurch einen Bezug zur Datei und zur aktuellen Quellversion. Du kannst sie später wieder öffnen, ergänzen oder als erledigt markieren.

Wenn mehrere Seiten betroffen sind, beginne mit einem Projektbericht und formuliere daraus einen Auftrag mit den relevanten Quellen. Gemeinsam verwendete Komponenten sollten dabei ausdrücklich genannt werden.
