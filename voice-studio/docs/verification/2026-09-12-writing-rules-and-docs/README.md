# Writing rules and documentation: retained browser checks

These JSON files preserve actual local checks on 12 September 2026. Each records
its own capture time and scope. Website reports include the tested build-input
hashes. Publishing these reports is a later documentation change; their original
observations do not silently become tests of every subsequent build.

- website.json: complete desktop/mobile EN/DE route and link checks.
- writing-patterns.json: actual rule catalogue, package playground, JSON records,
  source screenshots and no-JavaScript behavior.
- json-viewer.json: isolated renderer/viewer regression fixture.

No Studio session, project source or model was changed by these browser checks.
The separate writing-rules package tests cover code and declaration contracts;
these browser reports do not constitute a model benchmark or authorship-detector
qualification. The original report bytes are retained with SHA-256 hashes.
